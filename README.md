# Josco PNG ↔ JPG Converter

A lightweight, browser-based tool that allows users to instantly convert images between **PNG** and **JPG** formats.  
No database is used files are cleared after download, ensuring privacy and simplicity.

---

##  Features
- Upload `.png` or `.jpg` files
- Convert between PNG ↔ JPG instantly
- Preview converted image before download
- Download converted file directly
- File input clears automatically after download
- Responsive design with clean UI
- About section + LinkedIn profile embed
